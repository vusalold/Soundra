# Soundra 🎵
**YouTube to MP3 Downloader & Audio Player for Android**

Soundra is a modern, fast, and feature-rich Android application designed to download audio from YouTube in MP3 format and play music with an intuitive, premium interface.

---

## ✨ Features
- 🚀 **Fast MP3 Download:** High-speed audio extraction and conversion.
- 🎧 **Built-in Music Player:** Seamless playback with queue and background playback support.
- 📁 **Playlists & Library:** Organize downloaded tracks into custom playlists.
- 🎨 **Modern Neon UI:** Jetpack Compose interface with dark theme and dynamic visuals.
- 🔄 **In-App Auto Update:** Automatically checks for new releases directly from GitHub.
